### Career Connection

CST-239 concepts can support work in roles such as:

- **Java or backend developer:** Build services that handle requests, communicate with other systems, and manage concurrent work.
- **Software test engineer:** Write tests, reproduce defects, and check behavior across components.
- **Application or systems integration developer:** Connect software components through network protocols and APIs.
- **Network software developer:** Create or maintain software that sends and receives data across a network.

Explore current job descriptions. Note where employers ask for Java, networking, concurrency, testing, debugging, and communication skills. Compare those requirements with the projects you complete in class.

### Learn a Different Way

- [Dev.java learning hub](https://dev.java/learn/) — Current Java learning materials from the Java community.
- [Dev.java: virtual threads](https://dev.java/learn/new-features/virtual-threads/) — Learn how Java supports many concurrent tasks, especially tasks that wait on network input/output.
- [Oracle Java networking tutorial](https://docs.oracle.com/javase/tutorial/networking/index.html) — Explanations and examples for Java networking. This tutorial targets JDK 8, so use it for foundational concepts and check current Java documentation for newer APIs.
- [Oracle Java sockets tutorial](https://docs.oracle.com/javase/tutorial/networking/sockets/) — Client/server socket examples. Also targets JDK 8.
- [Java SE API documentation](https://docs.oracle.com/en/java/javase/21/docs/api/) — Reference for Java classes and methods. Match the documentation version to the JDK used in your course.

When using a video, book, article, or tutorial, compare its examples with the course JDK and assignment requirements.

### Practice the Skills

Try one or more independent exercises:

- Create a simple client and server that exchange a message, then add input validation and useful error handling.
- Build a multithreaded task runner. Record what happens when several tasks update shared data, then protect the shared state.
- Add automated tests for normal input, boundary cases, and failures.
- Compare a single-threaded solution with a concurrent version. Describe the benefits, tradeoffs, and risks.
- Find a small Java project on GitHub. Read its README, run its tests, and explain how it organizes networking or concurrency code.
- Write a short project README that explains the problem, setup steps, design choices, and how to run the tests.
